# 🧩 จับคู่คำศัพท์หรรษา

เกมจับคู่คำศัพท์สำหรับเด็ก ป.2 — เล่นคนเดียวไล่เก็บ 10 ด่าน, แข่งผลัดตาบนเครื่องเดียวกัน
หรือ **เปิดห้องออนไลน์เล่นพร้อมกันคนละเครื่อง** (ใส่แค่รหัสห้อง 4 หลัก ไม่ต้องสมัคร ไม่ต้องล็อกอิน)

โปรเจกต์นี้แยกจากระบบ ERP ของบ้านโดยสิ้นเชิง ไม่ใช้ตาราง ไม่ใช้ฐานข้อมูลร่วมกัน

---

## ในโฟลเดอร์นี้มีอะไรบ้าง

| ไฟล์ | ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บเกมทั้งหมด (โครงหน้า + สไตล์) |
| `game.js` | ตรรกะเกมฝั่งผู้เล่น — สร้างการ์ด, พลิก, คะแนน, ห้องออนไลน์ |
| `functions/api/room.js` | API ห้องออนไลน์ (Cloudflare Pages Function) — เป็นคนตัดสินว่าใครถึงตาเล่น |
| `schema.sql` | ตาราง `game_rooms` สำหรับฐานข้อมูล D1 |
| `tests/room.test.js` | ชุดทดสอบกติกาห้องออนไลน์ |

## ติดตั้งครั้งแรก (ทำครั้งเดียว ประมาณ 10 นาที)

### 1. เอาโค้ดขึ้น GitHub

```bash
cd ~/Desktop/work/word-match-game
git init
git add -A
git commit -m "เกมจับคู่คำศัพท์ + ห้องออนไลน์"
```

จากนั้นสร้าง repo ใหม่บน GitHub (ตั้งชื่อ `word-match-game` ก็ได้) แล้ว

```bash
git remote add origin https://github.com/<ชื่อผู้ใช้>/word-match-game.git
git branch -M main
git push -u origin main
```

### 2. สร้างฐานข้อมูล D1

เข้า Cloudflare Dashboard → **Storage & Databases → D1** → **Create database**
ตั้งชื่อว่า `wordmatch` → Create

เสร็จแล้วเข้าไปที่ฐานข้อมูลนั้น → แท็บ **Console** → วางทั้งหมดในไฟล์ `schema.sql` ลงไปแล้วกด Execute

### 3. สร้าง Cloudflare Pages

Dashboard → **Workers & Pages** → **Create** → แท็บ **Pages** → **Connect to Git** → เลือก repo ที่เพิ่ง push

ตั้งค่าตอนสร้าง:

| ช่อง | ใส่ว่า |
|---|---|
| Framework preset | **None** |
| Build command | **เว้นว่าง** |
| Build output directory | **`/`** |

กด **Save and Deploy** (รอบแรกห้องออนไลน์จะยังไม่ทำงาน เพราะยังไม่ได้ผูกฐานข้อมูล — ทำต่อข้อ 4)

### 4. ผูกฐานข้อมูลเข้ากับเว็บ ⚠️ ขั้นที่ลืมไม่ได้

ในโปรเจกต์ Pages ที่เพิ่งสร้าง → **Settings** → **Bindings** (หรือ Functions → D1 database bindings)
→ **Add binding**

| ช่อง | ใส่ว่า |
|---|---|
| Variable name | **`DB`** (ตัวใหญ่ทั้งสองตัว ห้ามพิมพ์ผิด) |
| D1 database | `wordmatch` |

ใส่ทั้ง **Production** และ **Preview** แล้วกด Save

### 5. Deploy ใหม่อีกรอบ

Deployments → deploy ล่าสุด → **Retry deployment**
(หรือ `git commit --allow-empty -m "redeploy" && git push`)

### 6. เปิดเล่นได้เลย

ลิงก์จะเป็นประมาณ `https://word-match-game.pages.dev` — ส่งให้ใครก็ได้ กดเข้าเล่นได้ทันที

## วิธีเล่นห้องออนไลน์

1. คนแรกเลือก **🌐 ห้องออนไลน์** → ใส่ชื่อ → เลือกภาษาและด่าน → กด **สร้างห้อง**
2. จะได้ **รหัส 4 หลัก** กับปุ่มคัดลอกลิงก์ → ส่งให้เพื่อน
3. เพื่อนเปิดเว็บเดียวกัน ใส่ชื่อ ใส่รหัส กด **เข้าห้อง** (หรือกดลิงก์ที่ส่งไป รหัสจะกรอกให้เอง)
4. เจ้าของห้องกด **เริ่มเกม** เมื่อครบคน (2–6 คน)
5. ทุกคนเห็นการ์ดพลิกพร้อมกัน ผลัดกันเปิดทีละคน — **ใครเปิดถูกได้เล่นต่อ** เปิดผิดเปลี่ยนตา
6. จบเกมขึ้นโพเดียม 🥇🥈🥉 เจ้าของห้องกดเล่นรอบใหม่ได้เลย

เซิร์ฟเวอร์เป็นคนตัดสินทุกอย่าง (ใครถึงตา การ์ดใบไหนเปิดอยู่ ใครได้คะแนน) เครื่องของผู้เล่นแค่วาดตาม
ทุกเครื่องจึงเห็นตรงกันเสมอ แม้แต่คนที่เน็ตช้ากว่า

## แก้ของในเกม

**เพิ่มคำศัพท์** — เปิด `game.js` หาตัวแปร `W` ข้างบนสุด เพิ่มบรรทัดในรูปแบบ
`["🦒","ยีราฟ","Giraffe","สัตว์"]` (อิโมจิ, คำไทย, คำอังกฤษ, หมวด)
หมวดที่มีอยู่: `สัตว์` `ผลไม้` `อาหาร` `ธรรมชาติ` `ของใช้`

**แก้ด่าน** — ตัวแปร `STAGES` ในไฟล์เดียวกัน · `mix` คือระดับความยากของแต่ละคู่
(`1` = รูปคู่รูป, `2` = รูปคู่คำ, `3` = ยากสุด) ใส่กี่ตัวก็เท่ากับจำนวนคู่ในด่านนั้น

**แก้สี/ฟอนต์** — อยู่ใน `<style>` ต้นไฟล์ `index.html` ตรงบล็อก `:root`

แก้เสร็จ `git push` แล้ว Cloudflare จะ deploy ให้เองอัตโนมัติภายในไม่ถึงนาที

## ข้อจำกัดที่ควรรู้

- ห้องที่ไม่มีใครแตะเกิน **12 ชั่วโมง** จะถูกลบทิ้งอัตโนมัติ (กันข้อมูลบวม)
- เข้าห้องได้เฉพาะตอนที่ยัง **รออยู่ในห้อง** — เกมเริ่มแล้วต้องรอรอบถัดไป
- สูงสุด **6 คนต่อห้อง**
- ทุกเครื่องถามเซิร์ฟเวอร์ทุก ~1 วินาที การ์ดที่เพื่อนพลิกจึงอาจช้ากว่าเครื่องเจ้าตัวไม่เกิน 1 วินาที
- D1 ฟรีรองรับได้สบายในระดับเล่นกันในบ้าน/ในห้องเรียน
